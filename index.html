Master Data

Versi ini memakai localStorage agar alur bisa diuji penuh di browser. Saat modul HPP asli digabung, data HPP dapat menggantikan nilai input manual tanpa mengubah struktur sistem.

Identitas Sistem

Informasi ini akan digunakan pada Dashboard dan area identitas sistem.
Pengaturan ini hanya mengubah identitas/tampilan. Modul Order, HPP, Produksi, Stok, Keuangan, dan Riwayat tidak diubah.

Pengaturan Nota

Atur tampilan nota tanpa mengubah nilai transaksi. Angka pada nota selalu dihitung dari item order yang tersimpan.
Jika order memiliki catatan sendiri, catatan order akan digunakan. Teks ini menjadi catatan default bila catatan order kosong.
Aturan angka: Subtotal = jumlah subtotal semua item. Total Tagihan = subtotal, kecuali nanti ada diskon yang benar-benar diinput. Diskon tidak akan muncul otomatis.
